# POROS-CJ-0.1 — Canonical JSON Profile

**Status:** PROPOSED / NOT LOCKED

Canonical bytes are UTF-8 JSON with lexicographically sorted object keys, preserved array order, compact separators, deterministic escaping, and rejection of non-finite numbers and duplicate keys. SHA-256 is computed over the exact canonical UTF-8 byte sequence and rendered as lowercase hexadecimal.

This profile is normative only after the applicable review and governance approval gates are completed. Until then it is a draft working contract.
